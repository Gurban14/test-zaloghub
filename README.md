# ZalogHub — список задач

Тестовое задание на React, TypeScript и Vite. Без сервера, API и библиотек для управления состоянием.

## Запуск

Нужен Node.js 20.19+ или 22.12+.

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
npm run preview
```

`build` сначала проверяет TypeScript, затем собирает приложение в `dist`.

## Возможности

- Добавление задачи кнопкой или Enter. Пробелы по краям удаляются, пустая строка не принимается.
- Переключение статуса через чекбокс. Выполненные задачи зачёркнуты.
- Удаление задач и фильтры «Все», «Активные», «Выполненные» со счётчиками.
- Сохранение задач в `localStorage` под ключом `zaloghub-tasks`.
- Адаптивный интерфейс и управление с клавиатуры.
- Карточки «В процессе» и «Уже сделано» переключают фильтр списка. Общий прогресс рассчитывается по выполненным задачам.

## Как устроен код

- `src/App.tsx` — состояние задач, обработчики и фильтрация.
- `src/components/TaskForm.tsx` — поле ввода и отправка формы.
- `src/components/TaskItem.tsx` — задача, чекбокс и удаление.
- `src/components/Icons.tsx` — небольшие SVG-иконки.
- `src/storage.ts` — чтение, проверка данных и запись в localStorage.
- `src/types.ts` — тип задачи и фильтра.
- `src/styles.css` — стили и мобильная версия.

Состояние инициализируется из localStorage один раз через ленивый `useState`. При изменении списка `useEffect` сохраняет его. Повреждённые данные не ломают страницу: некорректные записи пропускаются. Если браузер запрещает запись, приложение продолжает работать и показывает сообщение о невозможности сохранения.

Задачи хранятся только в текущем браузере. Фильтр не сохраняется. Шрифты и иконки не требуют подключения к внешним сервисам.

Outfit подключён локально из `public/fonts` (лицензия SIL OFL лежит рядом со шрифтом). Для кириллицы используется системный шрифт: San Francisco на macOS и iOS, Segoe UI на Windows.

## Ручная проверка

1. Попробовать добавить пустую строку и строку из пробелов.
2. Добавить несколько задач кнопкой и Enter; проверить обрезку пробелов.
3. Отметить задачу выполненной, проверить все три фильтра и счётчики.
4. Снять отметку, удалить задачу и обновить страницу.
5. Проверить, что оставшиеся задачи и их статусы восстановились.
6. Проверить интерфейс на узком экране и переключение элементов через Tab.
